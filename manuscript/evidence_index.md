# Claim-to-evidence index

This is the portable aggregate evidence for the integrated working manuscript. The files contain saved scores, summaries and source metadata; they contain no exact occurrence tables, native rasters, fitted models or raw survey histories. They add no fit, prediction or acquisition. Earlier reports describe development history and do not expand this package's scientific claims.

All paths below are relative to this `manuscript/` folder unless identified as original workspace paths. Every copied file's full SHA-256, byte count and original workspace-relative path appears in [source_data/source_manifest.json](source_data/source_manifest.json). Copies are byte-identical to their recorded sources. Original archive-relative paths identify inputs in the retained research archive; they are not public download links. The [source and access inventory](../SOURCES_AND_ACCESS.md) describes retrieval routes and omissions. Full original source receipts, including inherited native-data hashes, are preserved in [canonical_source_identity_receipts.json](source_data/canonical_source_identity_receipts.json); inherited native hashes were **not recomputed** during packaging.

## Source identities and citations

The complete copy manifest is the authoritative full-hash index. The original ecological and observation sources include:

- CHELSA 2.1, 1981–2010 normals: Karger et al. dataset [doi:10.16904/envidat.228](https://doi.org/10.16904/envidat.228). Family derivations and frozen physical-array paths remain in the packaged family-lineage table; the arrays themselves remain in the native archive.
- Western spadefoot biological comparison: Neal et al. 2018, [doi:10.1007/s10592-018-1066-7](https://doi.org/10.1007/s10592-018-1066-7). It supports the biological premise, not genetic identification of each geographic occurrence.
- USGS occurrence/survey release S35: [doi:10.5066/P9O7MC7M](https://doi.org/10.5066/P9O7MC7M); methods S36: Rose et al. 2022, [doi:10.1016/j.gecco.2021.e01944](https://doi.org/10.1016/j.gecco.2021.e01944); inspected official model code S94: [doi:10.5066/P9YYKW1H](https://doi.org/10.5066/P9YYKW1H). This package does not reproduce the released integrated model.

These citation identities are carried forward from the existing manuscript/source audit; no fresh literature acquisition occurred during packaging. Native source SHA-256 receipts include `presence_only_records.csv` `7f5a7dd78d528e12d8ef121a8257392eb8ce83c2b7d78311f52a87e012c78306`, `site_occupancy_data.csv` `2923e2e610cf9c09d20190a9dbd6f8832facc7a17209f7ff5523fc278beeccaf`, and `so_detection_covariates.csv` `5ce7fe0c0b6f1864286f8819d9ed032ff672eb4d274bb6ec8066e5b37f3411c9`. These are inherited identity receipts, not new raw-data checks.

## Portable replay

From this folder, ordinary Python with only its standard library checks file identities, all structured means/contrasts, the full seasonal family/contrast arithmetic, saved alignment counts, pooling contrasts, water comparisons, original seasonal procedures and coverage totals:

```sh
python3 replay/replay_aggregates.py
```

The default writes a new receipt under `rebuilt/`, leaving packaged evidence unchanged. `--output /tmp/spea-aggregate-receipt.json` chooses another destination. The completed receipt is [verification/aggregate_replay_receipt.json](verification/aggregate_replay_receipt.json). The earlier native-source audit is [verification/aggregate_native_source_audit_receipt.json](verification/aggregate_native_source_audit_receipt.json): 2,510 checks already completed; it was not repeated during packaging. Aggregate identity and arithmetic checks do not establish independent biological replication or source validity.

The three main figures rebuild from these packaged aggregate tables using Python, NumPy and Matplotlib, without native research files:

```sh
python3 replay/build_main_figures.py --output-dir /tmp/spea-main-figure-replay
```

An optional `--figure figure2_seasonal_representations` rebuilds only that figure. The builder preserves North/South labels and faint matched-fold connectors, writes its own output provenance into the chosen temporary folder, and does not overwrite packaged figures. It adds no confidence intervals, fits or predictions. Public portability and image-reproduction checks are recorded in [the release verification](verification/public_release_validation.json).

**Figure S1 is supplied as a rendered figure, not a portable native rebuild.** Rebuilding its geography requires the original local archive: the saved split NPZs, primary native-domain arrays, contextual boundaries, native grid metadata and saved held-cell display inputs identified in `seasonal_coverage_map_provenance.json`. The package omits those native arrays and coordinate-bearing inputs. The 2×3 layout was already checked against all five original map records and 3,914 displayed cells. Replaying aggregate counts does not reconstruct native masks, inspect original guards or validate location uncertainty.
